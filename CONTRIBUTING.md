# Contributing to CodeAtlas

Thank you for your interest in contributing to CodeAtlas!

## Repository Location
Official Repository: https://github.com/varunkulkarninagpur/codeAtlas

## Development Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/varunkulkarninagpur/codeAtlas.git
   cd codeAtlas
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Build CSS bundle:
   ```bash
   npm run build:css
   ```
4. Start local development server:
   ```bash
   npm start
   ```

## Pull Request Guidelines

- Ensure code passes `npm audit` and has zero console warnings.
- Keep commits atomic and descriptive.
- Follow semantic versioning.
