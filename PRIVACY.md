# Privacy Policy

**Effective Date:** July 23, 2026

CodeAtlas is committed to strict user privacy and developer data sovereignty.

## 1. No Telemetry & Zero Analytics
CodeAtlas does **NOT** collect, transmit, or store:
- Source code or Abstract Syntax Tree (AST) tokens.
- File names, directory structures, or package names.
- User IP addresses, device identifiers, or telemetry events.
- Usage tracking cookies or third-party analytics pixels.

## 2. 100% Local AST Execution
All parsing of Spring Boot annotations (`@RestController`, `@Service`, `@Repository`) and static dependency graph generation occurs exclusively within your local Visual Studio Code process.

## 3. Website Privacy
The CodeAtlas website (https://varunkulkarninagpur.github.io/codeAtlas/) contains:
- Zero tracking cookies.
- Zero analytics scripts (no Google Analytics, Mixpanel, or Facebook pixels).
- Zero third-party fingerprinting services.

## 4. Contact
For privacy questions, contact: **privacy@codeatlas.dev**
