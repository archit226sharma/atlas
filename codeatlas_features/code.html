Rule Configuration

Define rules using standard ArchUnit semantics directly in a `.codeatlas.yml` file or via the UI panel.

rules:
  - name: LayeredArchitecture
    type: layered
    layers:
      - Web: "com.example.web.."
      - Domain: "com.example.domain.."
      - Persistence: "com.example.data.."
    constraints:
      - Web mayNotAccess Persistence
      - Domain onlyDependsOn java..
