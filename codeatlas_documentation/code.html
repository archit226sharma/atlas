Getting Started with CodeAtlas

CodeAtlas provides a deep, architectural understanding of your Spring Boot applications directly within your IDE. Learn how to install, configure, and navigate your structural dependencies.

Installation

The quickest way to get started is by installing the extension via the VS Code Marketplace or from the command line using the extension CLI.

Terminal
$ code --install-extension codeatlas.engineering

Initializing a Workspace

Once installed, CodeAtlas needs to build an initial index of your Spring context. Run the initialization command from the command palette (Ctrl+Shift+P).

application.yml 
codeatlas:  scan:    base-packages: "com.example.enterprise"    exclude:      - "**/*Test.java"      - "**/generated/**"
