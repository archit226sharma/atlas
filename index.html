1. Installation & Setup

Install CodeAtlas directly from the Visual Studio Code Marketplace or via command line.

code --install-extension VarunKulkarni.codeatlas-vscode

2. System Requirements & Compatibility

  • IDE: Visual Studio Code 1.80.0 or newer.
  • Java JDK: Java 17 LTS or Java 21 LTS source code compatibility.
  • Spring Boot: Spring Boot 2.7.x through 3.3.x projects.
  • Build System: Maven (pom.xml) or Gradle (build.gradle / build.gradle.kts).

3. Extension Commands

CodeAtlas: Open Architecture Explorer Opens the interactive Webview dependency graph canvas for current workspace.
CodeAtlas: Analyze Project Triggers full AST scan and prints summary report in integrated terminal.

4. Configuration Schema (.vscode/codeatlas.json)

Customize analysis scope and rule enforcement weight in your project repository.

{
  "codeatlas.version": "1.0.0",
  "analysis": {
    "excludePackages": ["com.example.demo.generated.*"],
    "maxDepth": 10
  },
  "rules": {
    "enforceStrictLayering": true,
    "allowCircularDependencies": false,
    "flagUnusedBeans": true
  },
  "scoring": {
    "layerBypassPenalty": 20,
    "circularDependencyPenalty": 30,
    "unusedBeanPenalty": 5
  }
}

5. Architecture Rules Reference

BYPASS_SERVICE_LAYER

Triggers when a @RestController or @Controller class injects a @Repository interface directly without invoking an intermediate @Service layer.

CIRCULAR_DEPENDENCY

Triggers when two or more Spring Beans create a closed injection cycle (e.g. Bean A -> Bean B -> Bean A).

UNUSED_SPRING_BEAN

Triggers when a @Service, @Component, or @Bean method has zero inbound injection points in the parsed AST graph.

6. Known Limitations

  • Dynamic runtime reflection bean creation (`ApplicationContext.getBean(String)`) cannot be statically wired into AST graph.
  • Legacy XML bean configuration files (`applicationContext.xml`) are not parsed; Java annotation configuration is required.

7. Frequently Asked Questions

Q: Does CodeAtlas execute my Spring Boot application? A: No. CodeAtlas performs 100% offline static AST parsing. It never starts a JVM process or executes your code.
Q: Is my source code sent to any cloud servers? A: No. CodeAtlas operates completely offline inside VS Code. Zero network telemetry or cloud storage is involved.
