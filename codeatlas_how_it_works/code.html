Architecture Deep Dive

Static Analysis Engine

CodeAtlas operates entirely offline, performing rigorous static analysis on your Java source code to reconstruct the Spring Boot application context without executing a single line of code.

No cloud. No telemetry. No AI. 100% local analysis.
Phase 01 scanner

Scan

Rapidly indexes workspace directories, locating all `.java` files while respecting `.gitignore` and build tool exclusions to minimize I/O overhead.

Phase 02 code_blocks

Parse

Constructs Abstract Syntax Trees (AST) using a robust Java parser. Extracts class metadata, field signatures, and Spring stereotype annotations.

Phase 03 schema

Graph

Resolves dependencies by matching `@Autowired` fields, constructor parameters, and `@Bean` methods to their corresponding type definitions.

Phase 04 analytics

Analyze

Detects architectural smells like circular dependencies, missing configurations, and orphaned beans by analyzing the resulting dependency graph.

Annotation Parsing Logic

CodeAtlas relies on exact syntactic matching of Spring Framework metadata. Our AST visitor traverses class declarations looking for stereotype annotations to categorize architectural components.
